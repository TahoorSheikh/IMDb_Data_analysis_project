# IMDb Ratings Analysis

This is my project for the Scientific Data Analysis course at Ontario Tech University.
In this project I was required to perform EDA (Exploratory Data Analysis) on a data set of my choosing

The two data sets I choose was two IMDb data sets, one that contained the top 1000 rated TV shows,
and the bottom 1000 rated TV shows. 

The goal of this project was to find patterns/discovery on what might give a type of TV show a higher
or lower rating. I look at attributes like genre and year of release.
